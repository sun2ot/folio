## 自动测试

`pnpm test` 覆盖：v2 协议往返、错误版本/图片/颜色/重复字段、图片坐标边界、旧组件拒绝、结构化条目边界、模板保留内容、不可变拖动、Markdown 安全过滤和嵌套格式、多层列表、双栏、分页与超长模块。

`pnpm test:e2e` 启动 Vite，使用隔离的 Chromium 上下文；仅访问本地应用及本次导出文件，不访问外部站点。覆盖上述新增功能及编辑保存、模板切换、模块排序、手动预览、换页、JSON/HTML/PDF 下载、溢出时阻止导出。截图和下载在 test-results 中，不提交版本库。

## 排版发布清单

1. 三个模板分别检查有/无头像、圆形/方形、取景边缘、不同缩放位置。
2. 中文、英文、长 URL、加粗斜体高亮代码混合、多层列表、半宽长段落、空标题与空联系方式。
3. 1 / 2 / 10 页，手动换页与孤立半宽模块；验证超长模块提示阻止导出，不产生半行截断。
4. 四种字体分别等加载完成后导出，与 100% 预览比较：分页、标题线、字号、边界和图片位置。
5. HTML 用断网浏览器打开；确认字体图片在场、无网络请求、无编辑器、打印无额外空白页。
6. PDF 使用 Poppler `pdfinfo` 检查 A4 / 页数；`pdftoppm -scale-to 1200 -png file.pdf out` 视觉检查每页。二维码用真实手机扫描。
7. 原生打印设 A4 / 100% / 无边距 / 背景开启 / 页眉页脚关闭，验证可复制中文、链接和页数。
8. Chromium、Firefox、Safari 各完成一次上述流程。自动 Chromium 通过不能代替 Safari 打印兼容性验证。
9. 本地存储不可用、存储满、错误 JSON、超大/损坏图片时显示错误，不破坏原始文档。导入前先备份。
10. 手机窄屏、键盘 Tab、头像滑块、上移/下移、焦点与 modal Escape 退出。
11. 头像/二维码在 35%–120% 预览缩放下拖动、跨页、拖动中滚动、取消拖动；坐标与取景相互独立，Shift + 方向键、页码/尺寸输入、隐藏与新增空白页。
12. 基本信息 1/2/3 列，全部/部分/空字段；经历左右/左中右、半宽退化布局、空字段、长学校名/角色/时间、增删及排序。页眉与页脚长文本和独立开关在三模板及所有导出一致。

## 性能基线设计

输入后 220ms 触发预览，500ms 保存；Markdown Block 使用 memo；PDF 引擎动态加载，页面串行渲染，画布用后清空。导出开始冻结编辑避免页面中途变化。40 步历史只在会话中存在。性能指标需在目标设备实际测量，未以开发机运行时间代替通用性能承诺。
